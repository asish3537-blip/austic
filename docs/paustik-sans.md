# Paustik Sans 1.0

Original Latin outlines were drawn for Paustik using geometric stroke construction, with independently exported Regular 400, Semibold 600 and Bold 700 faces. No existing font file was opened or used as an outline source. Each face contains 169 glyphs covering English, common accented Latin, digits, punctuation and the rupee sign.

The website uses locally hosted WOFF2 files. The old Manrope alias and Google Fonts import were removed from the active website stack. Hindi and Odia continue to use the separately licensed Noto faces; they are not represented as exclusive Paustik designs. Android English UI uses the original Regular/Bold OTF files, while its Hindi/Odia selection retains Noto.

Downloads and a specimen are at `/brand/typeface`; the family ZIP is `/fonts/paustik/PaustikSans-Family.zip`. It contains OTF desktop files, WOFF2 web files, character coverage and the Paustik Brand Use Licence. Public access does not grant use for unrelated brands. No legal registration, trademark clearance or guarantee of enforceability is made.

Validation: each WOFF2 file was decompressed and parsed again; every printable ASCII character and the rupee sign resolved to a glyph. Original outline specimens were rendered and visually reviewed. These checks do not substitute for full professional type-engineering or accessibility certification.
