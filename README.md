# Paustik Marketplace

Paustik connects nearby households with meals prepared by verified mother entrepreneurs, with ordering, delivery, and operations workflows.

## Deployment

Deploy this Next.js application from the repository root. Configure production credentials in the hosting provider's environment settings; never commit `.env*`, `.secrets/`, `.data/`, or database files. Production authentication requires the hosted database, an `AUTH_SECRET`, and the configured verification/email providers. The local SQLite sign-in demo is development-only.
