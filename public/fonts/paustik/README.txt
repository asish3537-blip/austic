PAUSTIK SANS 1.0

Original rounded geometric Latin typeface for Paustik.
Weights: Regular 400, Semibold 600, Bold 700.
Files: installable OpenType (.otf) and browser Web Open Font Format 2 (.woff2).
Install: open an OTF file and choose Install in your operating system.
Web: use the @font-face declarations in paustik-type.css.

Coverage: English uppercase/lowercase, common accented Latin, digits,
punctuation, INR/Euro/Pound currency symbols and common arrows; 169 glyphs
per face. Hindi and Odia use the existing separately licensed Noto fallback
fonts. No claim is made that Paustik Sans contains custom Indic letterforms.
